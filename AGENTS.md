# Repository architecture guardian

For any change under this repository, first read:

- `system_deployment/architecture/AGENTS.md`
- `system_deployment/architecture/ARCHITECTURE.md`
- `system_deployment/architecture/FILE_INDEX.md`

All architecture rules, file ownership, change templates and checks are kept
in `system_deployment/architecture/`. Run the guard with:

```bash
python3 system_deployment/architecture/check_architecture.py
```
